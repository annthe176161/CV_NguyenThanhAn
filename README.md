# Nguyễn Thành An — Software Developer Portfolio & CV

Trang web 1-page giới thiệu bản thân và CV của Nguyễn Thành An, tối ưu để triển khai trực tiếp trên **GitHub Pages**.

## Cấu trúc thư mục

```text
.
├── index.html
├── README.md
├── .gitignore
└── assets/
    ├── css/
    │   └── style.css
    ├── js/
    │   └── main.js
    ├── images/
    └── cv/
        └── NguyenThanhAn_SoftwareDeveloper_CV.pdf
```

## Publish lên GitHub Pages

1. Push repository lên GitHub (nhánh `main`).
2. Vào **Settings → Pages**.
3. Trong mục **Build and deployment**, chọn **Deploy from a branch** → nhánh `main` → thư mục `/ (root)` → **Save**.
